# Smart Jump (Geode Windows prototype)

This is **a build and installation test only**. It currently logs a message when Geometry Dash loads its main menu.

**Not implemented yet:** early input correction across seven modes or spike/wall hitboxes at **99.5% of original size** (a reduction of 0.5%).

## Build without C++ tools
Open the **Actions** tab, select **Build Windows Geode mod**, and choose **Run workflow**. If the workflow succeeds, download the `smartjump-windows-prototype` artifact and extract the ZIP. Move the `.geode` file into your Geometry Dash `geode/mods` folder.

Based on the [Geode example](https://github.com/geode-sdk/example-mod) and [official build action](https://github.com/geode-sdk/build-geode-mod).
